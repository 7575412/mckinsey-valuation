# 엑셀 DCF 가치평가 매크로 (Open DART 연동)

엑셀에서 **티커만 입력하면** DART에서 재무를 가져와 매킨지식 DCF로 목표주가를
산출합니다. `DartValuation.bas` 하나만 임포트하면 됩니다.

## 설치
1. 엑셀에서 **Alt+F11**(VBE) → **파일 > 파일 가져오기** → `DartValuation.bas` 선택
2. 보안: **파일 > 옵션 > 보안 센터 > 매크로 설정**에서 매크로 허용 (또는 파일을 `.xlsm`로 저장)
3. 외부 참조 설정 **불필요** — 모든 COM 객체는 late binding(CreateObject)이라 자동 동작 (32/64비트 모두)

## 사용
1. VBE에서 `SetupValuationSheet` 실행 (F5) → `Valuation` 시트가 생성됩니다
2. `B3`에 **Open DART API 키** 입력 (무료: opendart.fss.or.kr)
3. `B1` 티커(6자리, 예 `060980`), `B2` 사업연도(예 `2024`) 입력
4. (선택) `B13` 현재가 입력 → **상승여력 + 역산성장률**까지 산출
5. `RunValuation` 실행 → `E`열에 결과 출력

버튼으로 만들려면: 시트에 도형 삽입 → 우클릭 **매크로 지정** → `RunValuation`.

## 입력 (B열)
| 셀 | 의미 | 기본 |
|---|---|---|
| B1 | 티커(6자리) | 060980 |
| B2 | 사업연도 | 2024 |
| B3 | DART API 키 | (필수) |
| B4 | 연결/개별 | CFS |
| B5 | 매출성장률 g | 0.05 |
| B6 | 영구성장률 g∞ | 0.025 |
| B7 | 무위험수익률 Rf | 0.035 |
| B8 | 시장프리미엄 ERP | 0.06 |
| B9 | 베타 β | 1.0 |
| B10 | 세전차입금리 Kd | 0.05 |
| B11 | 한계세율 t | 0.22 |
| B12 | 명시적기간(년) | 5 |
| B13 | 현재가(선택) | |
| B14 | 추정 ROIC(빈칸=실적) | |

## 출력 (E열)
NOPLAT · 투하자본 · 실효세율 · ROIC · WACC · EV · 주주가치 · 발행주식수 ·
**목표주가** · 상승여력 · 역산성장률 · 가치함정 여부

## 설계 메모 (중요)
- **계정을 한글 계정명이 아니라 `account_id`(예 `ifrs-full_Revenue`)로 매칭**합니다.
  덕분에 ① `.bas`가 순수 ASCII라 **CP949/UTF-8 인코딩 깨짐 문제가 없고**(임포트 안전),
  ② `매출액` 누락 시 `매출원가 + 매출총이익`으로 폴백, `법인세비용(수익)` 같은 라벨
  변형도 자동 처리됩니다.
- **차입금/사채는 `account_id`가 아니라 BS 계정명에 `차입금`/`사채`가 포함된 줄을
  합산**합니다(이자성 부채 기준). 일부 필러(예: 단기차입금)는 표준 ID 없이
  `-표준계정코드 미사용-`로 코딩되기 때문입니다. 그 한글 키워드는 `ChrW()`로
  만들어 `.bas`는 여전히 순수 ASCII입니다. **리스부채·기타금융부채는 차입금으로
  보지 않습니다** — 현대리바트처럼 차입 대신 리스로 조달하는 회사는 부채가 0으로
  잡힐 수 있습니다(보수적이지 않은 결과 주의).
- 계정 표기가 특이한 종목은 **`DumpAccounts` 매크로**를 실행하면 `Raw` 시트에
  `sj_div / account_id / account_nm / 금액`이 전부 덤프됩니다. 거기서 올바른
  계정ID를 찾아 `DartValuation.bas`의 해당 `Acc(...)` 후보에 추가하세요.
- 검증: 060980(HL홀딩스)·000100(유한양행)은 동봉된 파이썬 엔진과 목표가가 거의
  일치합니다.

## 주의 — 모델 적용 한계
영업-DCF는 **영업이익만** 할인합니다. 제약/바이오(라이선스·지분법·금융수익 비중 큰
기업)나 순수 지주사처럼 **가치의 상당 부분이 비영업 항목**인 회사는 목표가가 크게
저평가될 수 있습니다. ROIC < WACC면 "가치 함정"으로 표시됩니다.
